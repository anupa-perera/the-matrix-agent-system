Local-first agent framework

The Matrix Agent System

A Matrix-inspired local agent operating layer for your own computer, with browser onboarding, Obsidian-readable memory, provider setup, and guarded tool access.

Download for Windows All Downloads View Source
Runs locally on 127.0.0.1 during setup. Secrets are stored through the operating system credential store. Preview release: installers are not code-signed yet.

Windows

  1. Download the Windows ZIP.
  2. Right-click it and choose Extract All.
  3. Open the extracted folder.
  4. Double-click Install The Matrix.cmd.

macOS / Linux

  1. Open the latest release.
  2. Download the macOS/Linux archive.
  3. Extract it.
  4. Run sh install.sh.

One Command

For users comfortable with PowerShell:

irm https://raw.githubusercontent.com/anupa-perera/the-matrix-agent-system/main/install.ps1 | iex

Why This Page Is Safe To Use

Downloads come from the project's official GitHub Release assets. The release also includes SHA256SUMS.txt so advanced users can verify file checksums.

During setup, the app opens a browser page on 127.0.0.1, which means the setup page is served from your own computer.
