> Local-first agent framework

The Matrix Agent System

A Matrix-inspired local agent operating layer for your own computer, with browser onboarding, Obsidian-readable memory, provider setup, branded Windows shortcuts, guarded tool access, and OpenAI Codex sign-in through the official Codex app.

⊞ Windows ⌘ macOS / Linux ↓ All Downloads {} View Source
Runs locally on 127.0.0.1 during setup. Secrets are stored through the OS credential store. OpenAI Codex sign-in stays inside the official Codex app. Preview release: installers are not code-signed yet.

AI Connections

OpenAI Codex

Use an eligible ChatGPT/Codex subscription through the official Codex app or CLI. The Matrix does not copy or store Codex OAuth tokens.

Browser Sign-In

OpenRouter can connect from the setup screen with browser sign-in, then stores the returned key through the operating system credential store.

Local Or API Key

Ollama and LM Studio can run on this computer. OpenAI API, Anthropic, Gemini, Mistral, and custom endpoints can use API keys where required.

Installation

Windows

  1. Download the Windows ZIP.
  2. Right-click it and choose Extract All.
  3. Open the extracted folder.
  4. Double-click Install The Matrix.cmd.

macOS / Linux

  1. Open the latest release.
  2. Download the macOS/Linux archive.
  3. Extract it.
  4. Run sh install.sh.

One Command

For users comfortable with PowerShell:

irm https://raw.githubusercontent.com/anupa-perera/the-matrix-agent-system/main/install.ps1 | iex
